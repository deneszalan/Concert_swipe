# Soundcheck

Swipe through upcoming Budapest concerts, listen to each act in the embedded Spotify player, and keep a shortlist.

- Swipe right (or →) to shortlist, left (or ←) to pass, `z` to undo.
- Three piles: Remaining, Shortlist and Passed. Go through any of them as cards, or view it as a list.
- Order by date (soonest first) or shuffle into a random order; past dates drop off automatically.
- Picks are stored in the browser's localStorage only.
- Single static file: edit the `RAW` array in `index.html` to add or change shows.

Live site: https://deneszalan.github.io/Concert_swipe/
